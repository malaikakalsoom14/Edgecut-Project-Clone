# EdgeCut Furniture Website

A responsive furniture website built using HTML, CSS, and JavaScript.  
This project includes a modern UI, hero slider animation, responsive design, hamburger menu, blog section, testimonials, contact form, and footer section.

# Technologies Used

• HTML5  
• CSS3  
• JavaScript  

# Features

• Fully Responsive Design  
• Hero Section Slider Animation  
• Hamburger Menu for Mobile Screens  
• Furniture Products Section  
• Blog Section  
• Testimonial Section  
• Contact Form with Google Map  
• Modern Footer with Social Icons
